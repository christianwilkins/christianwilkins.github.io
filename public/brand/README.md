# Christian Wilkins profile kit

Canonical identity: `identity.json`.

- `social-card.png`: 1200 × 630 share image.
- `profile-banner.png`: 1584 × 396 profile banner, with space at left for a profile photo overlay.
- `avatar.png`: 1024 × 1024 export of the existing personal mark.
- `mark.svg`: original vector mark.
- `fonts/`: self hosted Newsreader and IBM Plex Sans with their licenses.

Usage and copy: `docs/brand-guidelines.md` in the repository.

Regenerate artwork from the project root with `PLAYWRIGHT_CHANNEL=chrome node scripts/render-brand.cjs`.
